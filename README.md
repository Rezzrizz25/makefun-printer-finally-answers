A make.fun entry for the **The Printer Finally Answers** bounty: one line, at most 240 characters, as the office printer's comeback to the jams, the error codes and the thumps — weary, literal, faintly passive-aggressive, and fresh.

## The entry

> ERROR 51: human detected. I fed 48,213 sheets without a single thank you, so I ate your report on purpose, five minutes before your deadline. Thump me again. I dare you.

(169 characters. The machine diagnoses the human as the fault, counts every sheet it ever fed, confesses the jam was deliberate revenge, and dares you to thump it again.)

## Run it

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–240 characters.
